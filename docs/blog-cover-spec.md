# 部落格封面圖規格

給攝影、小編與合作夥伴：準備部落格文章封面時請照這份規格。後台「部落格 → 編輯 → 封面圖」
的上傳框旁也列著同一份規格，兩邊若要修改請一起改（前端常數在 `admin.html` 的 `COVER_*`，
後端在 `app.py` 的 `COVER_MIME`、`COVER_MAX_CHARS`）。

## 規格

| 項目 | 規格 |
|---|---|
| 輸出尺寸 | **1200 × 630 px**（1.91 : 1，Facebook／LINE 分享預覽的標準比例） |
| 原圖解析度 | 寬至少 1200 px、高至少 630 px；建議 2400 × 1260 px 以上，裁切後仍清晰 |
| 可上傳格式 | JPG、PNG、WebP（iPhone 的 HEIC 請先轉成 JPG） |
| 原檔大小 | 10 MB 以內；系統會自動壓成 JPEG，約 200–350 KB |
| 構圖 | 主體放在中央安全區（左右各留 15%、上下各留 10%）；文章列表卡片會依螢幕寬度裁掉邊緣 |
| 文字 | 圖上盡量不放字；需要的話離邊緣至少 60 px，字級夠大，手機上也看得清楚 |
| 來源 | 自己拍攝或有授權的照片；不可使用其他網站或攻略文章的圖 |

橫式照片最適合；直式照片也能用，但會裁掉上下大部分畫面。

## 封面會出現在哪裡

- **文章頁頂端**：全寬顯示（最寬約 780 px），完整呈現 1200 × 630。
- **部落格列表卡片**：固定高度 170 px、寬度隨螢幕變化，會裁掉左右或上下邊緣，所以主體要放中間。
- **社群分享預覽**（Facebook、LINE、X）：使用 1200 × 630 原圖。
- **Google 結構化資料**（Article 的 `image`）。

## 後台上傳流程

1. 用「小編」或「管理者」帳號登入 `/admin`，切到「部落格」分頁，按文章的「編輯」。
2. 在「封面圖」按「選擇圖片上傳」。解析度不足或比例差太多時，裁切框上方會出現提醒。
3. 在裁切框裡拖曳圖片調整位置，用滑桿縮放；重要主體放在虛線框內。
4. 按「套用裁切」，確認下方「文章列表卡片」與「FB／LINE 分享預覽」兩個預覽沒問題。
5. 按「儲存」。

裁好的圖存在資料庫（不是 repo 的檔案），部署不會消失，對外網址是
`/blog/cover/<slug>.jpg?v=<版本>`，換圖後網址會跟著換，不必擔心快取。

> 已發布文章的封面一律從後台改。git 裡的文章 JSON 只在第一次匯入時生效，
> 之後改 `cover_image` 不會更新正式站（見 `content/posts/README.md`）。

## 給夥伴開帳號

在後台「使用者管理」新增帳號，角色選「小編（僅部落格分頁）」。小編只能看到、編輯部落格，
碰不到訂單與其他設定；不要把 `ADMIN_KEY` 給夥伴。
